## Descripción del proyecto
Este proyecto consiste en el desarrollo de un sistema de análisis de ventas utilizando Python.
El sistema procesa un dataset en formato CSV y realiza automáticamente distintas operaciones de análisis de datos, permitiendo obtener información relevante sobre las ventas realizadas.

El programa:
- Lee un archivo CSV de ventas.
- Calcula ventas totales.
- Identifica el producto más vendido.
- Agrupa ventas por mes.
- Genera automáticamente un gráfico de barras.
- Guarda un resumen de resultados en un archivo de texto.

El desarrollo fue realizado utilizando Google Colab y gestionado mediante GitHub y Jira.

## Dataset utilizado
Archivo:
`datos/ventas.csv`

Columnas del dataset:
- fecha
- producto
- cantidad
- precio
